# 测试策略

## 目标

用尽可能低的成本覆盖关键路径，保证记录、工具、内容与聚合在变更后仍可用。

## 测试分层

| 层级 | 工具 | 覆盖内容 |
| --- | --- | --- |
| 后端单元测试 | xUnit（.NET 10） | 领域规则、校验、纯函数 |
| 后端集成测试 | xUnit + `WebApplicationFactory` + 临时 SQLite | 端点、EF Core、事务、迁移 |
| 前端单元/组件 | Vitest + Testing Library | 工具函数、组件、状态展示 |
| 端到端 | Playwright | 记录 CRUD、工具使用、页面导航 |
| 契约测试 | OpenAPI + 生成的客户端 | 前后端 DTO 一致性 |

## 必须覆盖的路径

### 记录

- 创建、编辑、删除。
- 标签筛选 + 关键词检索组合。
- 草稿自动保存与离开提醒。
- 导出内容完整。

### 想法流

- 标签解析：`#养花#`、`#技术/React#`、连续标签、重复标签、非法空格、超长标签、标签数量上限。
- 创建、编辑、软删除；删除后列表与日历排除。
- 口令：正确、缺失、错误、未配置、限流 401/429/503。
- 时间线游标分页：无重复、无遗漏、标签筛选。
- 日历：站点时区跨 UTC 日期、52 周边界、未来日期 0、`total`/`maxCount`。
- 前端：未解锁/解锁流程、401 清除会话、提交中禁用、空/错误状态、日历 5 档与移动端滚动。

### 文章 Markdown

- 标题、列表、表格、引用、链接与代码块渲染。
- 目录锚点、重复标题、代码复制按钮。
- 原始 HTML 不被执行。

### 工具

- 二维码：空输入、超长输入、非法字符。
- Base64：文本与文件编解码、非法输入。
- ASCII：搜索、复制、空结果。

### 内容与聚合

- 最佳实践与 Cheat Sheet 的列表、检索、详情。
- 适配器成功、超时、返回异常结构。
- 缓存命中与过期展示。
- 数据源全部失败时主站仍可用。

### 数据

- 迁移在空库与已有库副本上均可执行。
- 外键与唯一约束生效。
- EF Core 查询无 N+1 与意外全表加载。
- 备份与恢复流程演练。

### 契约

- OpenAPI 生成成功且包含全部端点。
- 生成的前端客户端可编译通过。
- DTO 字段与前端使用一致。

## 测试数据

- 使用固定 fixture，不依赖真实外部接口。
- 外部适配器在测试中一律 mock（替换 `HttpMessageHandler`）。
- 集成测试使用临时 SQLite 文件或 `Data Source=:memory:`（注意连接生命周期）。
- 不把真实凭据写入测试。
- 时间相关逻辑注入固定 `TimeProvider`。

## 覆盖率

初期不以数字为目标，优先保证关键路径。建议：

- 领域规则与校验：≥ 80%。
- API 关键路由：≥ 70%。
- 前端关键交互：覆盖主流程与错误分支。

## CI 门槛

1. 安装 Node 与 .NET SDK 10。
2. 前端安装依赖、lint、`npm run test:run`、构建。
3. 后端 `dotnet restore`、`dotnet build`、`dotnet test`。
4. 端到端测试（可 nightly 或发布前执行）。

任何一项失败都不得发布。

## 手动验证

自动化无法覆盖的项：

- 深浅主题与响应式布局。
- 键盘操作与焦点顺序。
- 外部工具嵌入（Excalidraw）加载与兜底。
- 队列/后台任务的真实运行（可用日志与手动触发验证）。
