# 博客整体设计与实现计划

## 问题与目标

我们需要为个人技术博客建立一个温暖、清晰、适合长内容阅读的视觉系统，并先聚焦 `技术学习分享` 这一核心功能。该博客内容包括技术学习记录、参考文档、Cheatsheet、小工具实现、随笔与读书心得，因此设计必须兼顾：

- 文章可读性
- 文档查阅效率
- 主题切换体验
- 温暖而稳定的产品感

## 设计原则

1. 温暖优先，不追求冷硬极简
2. 以可读性为第一目标，重视正文、列表、代码与引导层级
3. 只保留深色 / 浅色两种主题，保持统一语义变量和切换逻辑
4. 按功能维度定义配色范式，而非单一“单色全局覆盖”
5. 首期实现以技术学习文章为核心，后续再扩展文档页、Cheatsheet、随笔页和工具页

## 方案概览

### 1. 视觉方向

将博客定位为“温暖技术文档型博客”：

- 视觉上偏出版物和笔记本，少营销感，多信息结构感
- 页面语言以简洁、稳定和可信为主
- 强调留白、文字层级、低饱和度色彩和温和交互

### 2. 主题系统

保留两种主题：

- 浅色主题：适合长期阅读、学习笔记与技术文章
- 深色主题：适合夜间阅读、代码浏览与文档查看

统一使用 CSS 变量或 token 体系来维护语义色：

- background
- surface
- card
- text
- text-muted
- border
- accent
- accent-soft
- code-bg
- code-text
- link
- hover
- shadow

### 3. 功能型配色范式

不同内容类型会复用统一色板，但在语义上提供差异化：

- 技术学习分享：以温暖主色（赭色 / 土色）为主，突出积极学习感
- 参考文档 / Cheatsheet：偏稳定的中性色 + 柔和蓝灰，强调信息检索感
- 小工具实现：可加入更清晰的高亮与状态色，但不能破坏整体温暖
- 随笔 / 读书心得：允许更柔和、书页化的暖色过渡

这使得“功能不同，视觉语义不同，但整体仍属于同一套设计语言”

### 4. 排版规范

- 中文字体优先使用现代无衬线字体，英文与代码使用更清晰的 mono / sans 组合
- 正文行高适中，优先保证长文可读性
- 标题层级清晰，信息之间留出呼吸空间
- 文章页使用较宽的阅读区，保持舒适节奏
- 代码块和引用块使用清晰的区分样式，不打断正文节奏

### 5. 首期功能实现范围

先实现 `技术学习分享` 功能，目标包括：

- 文章列表页
- 文章详情页
- 分类/标签展示
- 简洁的目录导航
- 代码块和引用块样式
- 浅色/深色切换
- 适合长文和知识记录的阅读体验

## 备注

- 先做设计和文档，再进入实现，避免造型风格和功能结构脱节
- 主题切换依赖统一的 CSS 变量，而不是零散的局部覆盖
- 后续扩展功能时，要保持同一设计语言，避免“每个页面自成一套”
- 视觉重点应始终放在内容和阅读体验，而非炫技效果
