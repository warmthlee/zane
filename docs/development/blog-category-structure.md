# 博客分类页结构说明

## 目标

将原本依赖文章列表筛选的分类入口，提升为独立的分类详情页，形成更接近"个人技术博客"的浏览流：

- 首页 -> 分类页 -> 文章页
- 通过分类清晰区分内容边界
- 在不同主题下展示更丰富的内容摘要和阅读入口

## 结构设计

- 采用六大内容板块：技术学习分享、参考文档、小工具实现、随笔写作、读书心得、Cheatsheet
- 分类页中的按钮和筛选逻辑保留为 "全部 / 分类 / 标签 / 年份" 的统一入口
- 选中某个分类后，页面展示该类文章总览、摘要信息和快速切换列表
- 文章卡片继续保留收藏、草稿与阅读进度状态，便于在内容浏览中保持个性化体验

## 交互原则

1. 分类页是内容入口，而不是仅仅对列表做过滤
2. 允许用户在同一栏目中快速切换到其他主题，而不是被困在文章列表过滤器中
3. 文章内容仍保持与列表页、归档页的一致状态，不额外引入后端数据源
4. 侧重轻量、可维护的客户端渲染，适合当前静态博客的规模

## 当前实现效果

- 点击首页的内容模块卡片可进入对应分类页
- 顶部导航增加 "分类" 快速入口
- 分类页展示该板块的文章列表、状态罗盘与快速导航
- 文章主体仍可继续进入详情页并保持收藏、标签、阅读进度等状态

## 后续扩展

如果后续内容量明显增长，可以考虑进一步拆分为真实的路由页面，例如：

- /category/:slug
- /posts/:id
- /library

但在当前阶段，保留单页应用结构能保证更低维护成本和更稳的发布体验。
