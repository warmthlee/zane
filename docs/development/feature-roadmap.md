# 功能实现路线图

## 当前阶段：技术学习分享

本阶段的目标是先建立博客最核心的内容展示机制：

- 文章列表页
- 文章详情页
- 文章元信息：分类、标签、日期、时长
- 代码展示与章节结构
- 浅色和深色切换

## 页面目标

### 1. 首页

首页承担“博客入口”的角色：

- 介绍博客定位
- 展示最新/精选内容
- 引导进入文章列表或学习归档
- 让用户快速感受到温暖、稳定、可持续学习的氛围

### 2. 学习记录页

这是首期最重要的页面：

- 左侧列表导航
- 右侧正文内容
- 支持文章切换
- 保持长文阅读体验

### 3. 关于页

用于说明：

- 博客想传递什么价值
- 内容的方向与写作意图
- 读者愿意持续跟进的原因

## 后续扩展阶段

### 参考文档 / Cheatsheet

- 左侧目录结构
- 右侧核心说明与示例代码
- 更适合快速检索的布局

### 小工具实现页

- 展示小脚本、工具函数与在线 demo
- 使用更强调功能的高亮语义

### 随笔与读书心得

- 提供更“书页感”的排版
- 更适合长段落和思考性的写作

## 设计守则

- 技术学习分享优先，不让其他页面破坏基础阅读体验
- 统一主题系统，禁止局部“随意上色”
- 先做结构稳定，再扩展内容类型
- 保持文章页比展示页更重要
