# 功能型页面设计风格规范

## 1. 设计原则

所有页面都要遵循统一的博客母体：

- 统一浅色 / 深色两种主题
- 共享同一套字体、间距和层级系统
- 功能差异只体现在色彩语义、布局密度和交互重心上
- 不能用“每页一套风格”的方式打散体系

简短说：

- 统一设计语言
- 不同功能有不同阅读任务
- 阅读任务决定页面结构和色彩重点

## 2. 参考文档页：理性、专业、可检索

### 设计目标

参考文档页的核心体验是“查找信息”而不是“沉浸式阅读”，因此它应该比文章页更密、更结构化、更快速。

### 设计特征

- 版式：左侧目录，右侧正文内容
- 视觉重点：目录层级、章节标题、关键提示块
- 语气：专业、清晰、理性
- 交互：目录点击、锚点跳转、代码示例优先

### 视觉语言

- 主色优先使用柔和蓝灰 / 霜灰 / 落叶灰系
- 页面中大量用中性色和边框，减少视觉噪声
- 章节标题更醒目，强调信息分层
- 代码块和参数表格允许更强的对比，但不能刺眼

### 推荐色板（功能增强）

浅色主题：
- accent: #7F8EA6
- accent-soft: #E7EAF0
- border: #D8DEE5
- surface: #FBFCFD
- code-bg: #F3F5F8

深色主题：
- accent: #A7B5C8
- accent-soft: #2B3440
- border: #3A4450
- surface: #1F252D
- code-bg: #161C23

### 适用场景

- 工具使用说明
- API 和配置文档
- 面向检索的知识页
- 术语说明和项目约定

## 3. Cheatsheet 页：紧凑、速查、任务导向

### 设计目标

Cheatsheet 页的阅读任务是“快速找到答案”，不是“慢慢读完一篇文章”。

### 设计特征

- 页面结构更紧凑，适合列表、卡片、表格和命令块
- 重点放在“关键命令 / 关键配置 / 关键步骤”
- 视觉层级要强于一般长文，但整体仍要保持温暖
- 允许小面积高亮色，但不能让页面变得过于彩色

### 视觉语言

- 更适合“高密度信息页”
- 行高要更紧凑，标题清晰，分组明确
- 代码块和命令行通常为展示主角
- 颜色用于状态和分组，而不是大量装饰

### 推荐色板（功能增强）

浅色主题：
- accent: #869E8B
- accent-soft: #E8EFEA
- warn: #C98A5B
- surface: #FBF9F6
- code-bg: #F2EFEA

深色主题：
- accent: #9FB7A7
- accent-soft: #2D3A34
- warn: #D49C76
- surface: #1F1E1C
- code-bg: #121514

### 适用场景

- 命令速查
- 关键步骤列表
- 键盘快捷键或配置对照表
- 快速索引页

## 4. 小工具页：清晰、实用、可交互

### 设计目标

小工具页强调“功能性”和“可操作性”，不应该像文章页那样偏文艺或长段落式阅读。

### 设计特征

- 更强调交互控件、参数区、示例区和结果区
- 使用组块结构：输入区、操作区、输出区
- 尺寸和状态要清晰，能快速区分“可用 / 加载 / 成功 / 错误”
- 允许使用更直接的强调色，但仍要保持博客整体温暖感

### 视觉语言

- 页面上通常有明显的功能分区
- 表单输入、按钮、状态提示需要明确层级
- 工具说明文字可以简短，但必须保持一致的结构
- 输出区最好使用轻柔卡片风格，避免过强的区域分割

### 推荐色板（功能增强）

浅色主题：
- accent: #C7774E
- success: #6F8E6A
- info: #7E90AD
- warning: #D39B75
- surface: #FFFDF9

深色主题：
- accent: #D39B75
- success: #9CB79C
- info: #A7B7CF
- warning: #E4B589
- surface: #241F1D

### 适用场景

- 代码片段生成器
- 小型在线工具
- 参数转换器
- 轻量 demo 页面

## 5. 读书心得页：柔和、书页感、慢阅读

### 设计目标

读书心得页是最“文本导向”的页面，重点是让人愿意停下来阅读、思考和沉浸式理解。

### 设计特征

- 更大标题、更宽正文区域、更松散的段落间距
- 强调引用、思考与感悟，而不是功能性强的布局
- 页面可带有“纸张/书页”的温暖质感
- 允许较多留白，制造放松的阅读感

### 视觉语言

- 颜色以暖米、木色、浅泥和柔和苔绿为主
- 页面背景可以更偏纸张感，而不是纯白
- 引用块和感悟块可以轻描淡写，不要过于强烈
- 标题和正文之间的呼吸空间比技术内容页更大

### 推荐色板（功能增强）

浅色主题：
- accent: #B88B63
- accent-soft: #F1E5D8
- surface: #F9F4EE
- quote-bg: #F2E8DF
- border: #E4D7CA

深色主题：
- accent: #D6A67D
- accent-soft: #3A2E2A
- surface: #221C1A
- quote-bg: #312926
- border: #483C37

### 适用场景

- 读书笔记
- 随笔和生活感想
- 学习反思
- 比较轻松、表达性强的内容

## 6. 统一页面范式

### 视觉层级的统一规则

所有页面都遵循：

- 标题 > 章节 > 正文 > 说明信息
- 颜色只用于强调，不用于堆叠大量噪声
- 互动元素不超过 1–2 个主强调色
- 页面都要有清晰的边距和呼吸空间

### 主题切换规则

- 浅色模式用于长读和知识沉淀
- 深色模式用于代码、夜间阅读和信息密集页
- 浅深切换只切换主题色，不切换结构框架

### 组件复用规则

页内可复用的基础组件：

- 标题栏
- 标签 / 分类
- 卡片容器
- 引用块
- 代码块
- 分组列表
- 状态提示

任何功能页的差异，应该只发生在：

- 内容密度
- 语义色的重心
- 交互优先级
- 阅读节奏

而不是整体视觉体系完全重写。

## 7. 实施建议

1. 保持统一的母体：浅色/深色、字体、间距、边框、圆角
2. 在页面层面对功能差异做微调，而不是完全拆分设计语言
3. 让每种页面都能被用户“读懂它的目的”而不依赖解释
4. 内容体验永远优先于视觉噱头

## 8. 结论

这几类页面的设计差异需要明确，但它们都必须属于同一套博客系统：

- 参考文档页：专业与检索导向
- Cheatsheet 页：效率与扫描导向
- 小工具页：功能与交互导向
- 读书心得页：温暖与慢阅读导向

这样能保证博客的作品既有功能上的多样性，又维持强一致性的整体审美。
