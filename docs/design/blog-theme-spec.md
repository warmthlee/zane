# 博客主题设计规范

## 1. 设计定位

这是一个以“温暖、理性、知识沉淀”为核心的技术博客。整体气质不是冷硬营销站，而是像一本真实写作的技术笔记：

- 讲究阅读体验
- 重视信息层级
- 接受内容为主导
- 允许温度存在于页面细节中

## 2. 两种主题设计

### 浅色主题：学习与书写

适合：
- 技术学习分享
- 随笔与读书心得
- 文章列表页
- 长阅读场景

特征：
- 背景偏暖白、米白、浅灰
- 正文颜色深稳，利于阅读
- 主色以暖系赭色或土色为主
- 边框与分隔线轻而清晰

### 深色主题：代码与文档

适合：
- 代码浏览
- 文档与查阅页
- 夜间模式

特征：
- 背景偏墨灰、深褐、深蓝灰
- 文字保持高对比但不刺眼
- 代码块与侧边目录维持更强的区分
- 色彩饱和度适中，仍保留温暖调性

## 4. 功能型配色范式

### A. 技术学习分享

目标：突出知识产出、学习过程和文章内容。

- 主色：暖赭色系
- 使用方式：标题强调、标签、按钮、章节高亮
- 语义：积极、稳定、适合长期记录

### B. 参考文档 / Cheatsheet

目标：强调效率、查找和结构。

- 主色：柔和蓝灰 / 落叶灰
- 使用方式：目录、快捷键、提示信息、字段标注
- 语义：专业、清晰、逻辑感强

### C. 小工具实现

目标：突出交互、功能、状态。

- 主色：可添加少量清晰高亮
- 使用方式：示例按钮、提示状态、参数块
- 语义：清晰、实用，不破坏全局温暖

### D. 随笔 / 读书心得

目标：稳定而柔和，强调内容和思考。

- 主色：浅木色、暖米色、柔和苔绿
- 使用方式：边框、语段强调、分隔条
- 语义：舒适、书页感、温暖

## 5. 版式规范

### 字体

- 中文：思源黑体 / Noto Sans SC / PingFang SC
- 英文：Inter / system-ui
- 代码：JetBrains Mono / Fira Code / SFMono-Regular

### 文字层级

- H1：24–32px，文章标题重点
- H2：20–24px，章节标题
- H3：16–18px，子章节
- 正文：16px，行高 1.75
- 次要说明：14px，行高 1.6

### 组件规范

- 卡片：极轻圆角，适度边框，轻阴影
- 按钮：圆角 8–12px，hover 变化平滑
- 代码块：带浅背景、不宜过黑或过亮
- 引用块：左侧轻色竖线，突出引用内容
- 列表：适中间距，段落分明，便于快速扫描

## 6. 交互规范

- hover 和 focus 需要柔和，不要过度动画
- 深浅两种主题保持统一的层级和可读性
- 能通过 CSS 变量一键切换，不要出现局部主题漂移
- 默认关闭过度的视觉噱头，突出内容本身

## 7. 第一期侧重点

首先实现“技术学习分享”页。此时应该满足：

- 符合温暖技术博客气质
- 强化正文可读性
- 可视化文章列表与详情页
- 集成主题切换
- 保证后续文档/工具页可以复用同一套风格规则

## 8. 实施原则

在实现过程中，保持下面的规则：

1. 使用统一的 token，不散落地写死颜色
2. 只允许浅/深两种主题切换
3. 功能型配色按语义使用，不同功能间保持同一设计语言
4. 优先可读性和稳定感，而不是视觉刺激
5. 内容页永远比装饰更重要
