# PRD-07 · Cheat Sheet

- 状态：planned
- 阶段：阶段 2

## 背景与目标

提供面向速查的命令、配置与流程清单，降低重复查找成本。

## 用户故事

- 作为作者，我可以创建按分类组织的速查表。
- 作为访客，我可以搜索并快速定位条目。
- 作为访客，我可以一键复制代码或命令。

## 功能要求

| 编号 | 要求 | 优先级 |
| --- | --- | --- |
| CHT-01 | 速查表列表与分类 | P1 |
| CHT-02 | 关键词搜索 | P1 |
| CHT-03 | 代码块一键复制 | P1 |
| CHT-04 | 内容可由思想记录复用生成 | P2 |
| CHT-05 | 排序与置顶 | P2 |

## 内容结构

- 每条速查项：标题、说明、代码/命令、注意事项。
- 按分类分组，组内保持稳定顺序。

## 验收标准

- [ ] 搜索可命中标题与正文。
- [ ] 代码块可复制且保留格式。
- [ ] 空结果有明确提示。
