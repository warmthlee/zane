# PRD-06 · 第三方工具集成

- 状态：planned
- 阶段：阶段 4

## 背景与目标

嵌入常用外部工具，减少工具切换成本。首批为 Excalidraw。

## 用户故事

- 作为作者，我可以从站点直接打开白板工具。
- 作为访客，外部工具不可用时仍能通过链接访问。

## 功能要求

| 编号 | 要求 | 优先级 |
| --- | --- | --- |
| INT-01 | 集成注册表：名称、slug、提供方、启用状态 | P2 |
| INT-02 | Excalidraw 嵌入页 | P2 |
| INT-03 | 加载超时与失败兜底 | P2 |
| INT-04 | 第三方来源与数据边界说明 | P2 |

## 约束

- 集成不得改变主站路由与全局状态。
- 嵌入失败必须提供外部链接。
- 不把第三方脚本的凭据或用户数据带入主站。
- 第三方内容需明确标注来源。

## 验收标准

- [ ] 集成页可正常加载。
- [ ] 失败时展示兜底链接。
- [ ] 不影响其他页面构建与运行。

## 开放问题

- 使用 iframe 嵌入还是官方 SDK？优先 iframe，隔离更彻底。
