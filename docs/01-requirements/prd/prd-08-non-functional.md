# PRD-08 · 非功能需求

- 状态：planned
- 适用：全项目

## 性能

| 项 | 目标 |
| --- | --- |
| 首屏可交互 | ≤ 2s（本地网络） |
| 工具页响应 | ≤ 200ms（纯前端工具） |
| API P95 | ≤ 500ms（不含外部抓取） |
| 聚合页 | 读取缓存，不阻塞请求 |

## 可用性

- 外部数据源失败时主站可用。
- 单个 MVP/集成失败不影响其他模块。
- 健康接口能反映数据库状态。
- 发布可回滚。

## 安全

- 写接口在鉴权落地前仅限本机或内网访问；Memos 写接口额外要求共享口令（ADR-010）。
- 数据库文件不通过静态目录暴露。
- 密钥通过环境变量或密钥管理注入；`Memos__Passphrase` 不写入仓库、前端产物或日志。
- 日志不记录密码、口令、Token 与敏感正文。
- 外部输入统一校验（DataAnnotations / 自定义校验器）。
- 依赖定期更新，关注安全公告。

## 数据

- SQLite 每日备份，保留至少 7 份。
- 支持 Markdown/JSON 导出。
- 迁移可重复执行且有记录。
- 破坏性迁移必须先备份。
- 时间统一 UTC 存储；日历与展示按 `Site:TimeZone` 转换。

## 可维护性

- 单一后端框架（.NET 10）与单一数据访问方式（EF Core）。
- 前后端共享类型与校验规则。
- 代码结构按领域组织，避免巨型端点文件。
- 关键路径有测试与日志。

## 可访问性

- 键盘可完成主要流程。
- 焦点可见，语义化标签。
- 深浅色对比度达标。
- 尊重 `prefers-reduced-motion`。

## 兼容性

- 支持最近两个版本的 Chrome、Edge、Firefox、Safari。
- 移动端可用，不要求原生 App。

## 合规与隐私

- 只采集必要数据。
- 第三方数据遵守来源条款。
- 提供数据导出与删除能力（鉴权落地后）。
