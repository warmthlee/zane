# PRD-04 · 最佳实践

- 状态：planned
- 阶段：阶段 3

## 背景与目标

沉淀设计模式、工程经验与真实案例，形成可复用的判断框架，而不是零散文章。

## 用户故事

- 作为作者，我可以按主题、技术栈、难度组织最佳实践。
- 作为读者，我可以快速理解问题、方案与适用边界。
- 作为读者，我可以复制代码示例。

## 功能要求

| 编号 | 要求 | 优先级 |
| --- | --- | --- |
| PAT-01 | 内容模型：问题、方案、代码、取舍、边界 | P1 |
| PAT-02 | 按主题/技术栈/难度筛选 | P1 |
| PAT-03 | 与思想记录共享标签与检索 | P1 |
| PAT-04 | 代码块复制 | P1 |
| PAT-05 | 设计模式案例首批内容 | P2 |

## 内容结构

每篇必须包含：

1. 问题背景与约束。
2. 方案与关键代码。
3. 取舍与替代方案。
4. 适用边界与反例。

## 验收标准

- [ ] 内容结构统一，可被检索。
- [ ] 代码示例可复制且可运行（或明确标注伪代码）。
- [ ] 过时内容可标记归档。
