# PRD-09 · 想法流（Memos）

- 状态：planned
- 阶段：阶段 3（首页、想法流与全局入口）
- 关联：PRD-00、PRD-01、ADR-007、delivery-plan-phase3

## 背景与目标

首页需要一个比文章更轻的记录入口：随手写下短想法，用标签归类，之后可以继续编辑和删除。交互参考 flomo 的想法流，但不引入 flomo 的账号、社交、付费或多端同步能力。

目标是让“记录”足够快：打开首页即可写，回车或点按钮提交，想法立即出现在时间线里；同时通过一个共享口令保护写操作，避免在无鉴权阶段被陌生访客随意修改。

## 边界

### 当前范围

- 短文本想法，纯文本，不渲染 Markdown。
- `#标签#` 语法，标签从正文中解析。
- 创建、编辑、删除；删除使用软删除。
- 共享口令保护创建、编辑、删除。
- 按时间倒序的时间线，游标分页。
- 最近 52 周的想法日历，按天聚合。
- 加载、空、错误、重试状态。

### 不包含

- 用户账号、登录、每条想法的所有者与权限判断（ADR-007，未来 MEMO-11）。
- 多用户、评论、点赞、转发、关注等社交能力。
- Markdown、富文本、图片上传、附件。
- 社交平台同步（ADR-008）。
- 公开写接口；写接口仍只在本机/内网或受信网络开放。
- 全文检索、复杂标签管理页（后续按需扩展）。

## 用户故事

- 作为作者，我可以在首页快速写下一个想法并提交。
- 作为作者，我可以用 `#养花#` 这样的标签给想法归类。
- 作为作者，我可以修改已发布的想法，修正措辞或标签。
- 作为作者，我可以删除不再需要的想法，删除前有确认。
- 作为作者，我可以看到最近一年每天记录了多少想法。
- 作为作者，我在输入正确口令后才能创建、编辑和删除想法。
- 作为读者，我可以阅读想法时间线和日历，但默认不能修改。

## 交互与页面

### 首页结构

```text
SiteHeader（六模块导航）
想法日历（导航下方第一块）
想法标题 + 口令入口
想法输入框
想法时间线
最近文章
```

### 输入框

- 单列窄版，多行文本，自动增高到约 6 行后内部滚动。
- 占位文案同时提示内容和标签语法：`记录一个想法… 用 #标签# 归类`。
- 右下角显示 `当前字数/500`；超过 500 字禁用提交并给出错误。
- `Ctrl/Cmd + Enter` 提交；提交中按钮显示“记录中…”并禁用。
- 未解锁时点击提交或编辑，弹出共享口令对话框；解锁成功后继续原操作，不丢失输入内容。

### 时间线

- 按自然日分组，日期标题使用站点时区。
- 每条显示：时间（`HH:mm`）、正文、标签胶囊、编辑/删除按钮。
- 标签渲染为可点击胶囊，显示为 `#养花#` / `#技术/React#`；点击后按标签值（不含 `#`）筛选，再次点击或“全部”清除。
- 编辑使用行内文本域，保存/取消；保存后标签重新解析。
- 删除使用确认对话框，确认后从列表和日历移除。
- 空状态：「还没有想法。写下第一条吧。」
- 错误状态：可读消息 + 重试；不阻塞页面其他区块。

### 日历

- 位置：导航栏正下方，输入框上方。
- 形态：7 行 × 52 列，周一开始，最近 52 周。
- 颜色：品牌橙 5 档；0 条使用低对比底色。
- 摘要：`过去一年 N 条想法 · 最多一天 M 条`。
- 图例：`少 [5 格] 多`。
- 移动端：日历容器内部横向滚动，默认滚到最右侧当前周；页面本身不横向溢出。
- 未来日期显示为空格子，不参与 `total` 与 `maxCount`。
- 无障碍：整块提供 `aria-label` 摘要；每格 `title` 为 `YYYY-MM-DD：N 条想法`；颜色不是唯一信息载体。

## 标签语法

- 标签以 `#` 开始和结束：`#养花#` 表示标签 `养花`。
- 支持嵌套：`#技术/React#` 表示标签 `技术/React`。
- 允许 Unicode 字母、数字、下划线、连字符；层级分隔符为 `/`。
- 不允许空格、换行、`#` 出现在标签内部。
- 单个标签最长 32 字符；每条想法最多 8 个标签；重复标签去重。
- 超过标签长度或数量上限时，创建/编辑返回 400（`MEMO_TAG_TOO_LONG` / `MEMO_TAG_LIMIT_EXCEEDED`），不静默丢弃。
- 解析在服务端执行，前端可做同样的预览，但以服务端结果为准。
- 参考正则：

```text
(?<![\w/])#([\p{L}\p{N}_-]+(?:\/[\p{L}\p{N}_-]+)*)#
```

- 标签按出现顺序返回；API 的 `tag` 参数按精确值筛选。

## 数据与接口

### 表

| 表 | 关键字段 | 说明 |
| --- | --- | --- |
| `memos` | id, content, created_at, updated_at, deleted_at | 想法正文与时间戳 |
| `memo_tags` | id, memo_id, tag | 从正文解析出的标签 |

- `memos.deleted_at` 为软删除标记；默认查询过滤器排除非空值；`memos(deleted_at, created_at)` 支持时间线。
- `memo_tags(memo_id, tag)` 唯一索引；`memo_tags(tag, memo_id)` 支持标签筛选。
- 时间统一 UTC 存储；展示与日历按 `Site:TimeZone` 转换。

### 端点

| 方法 | 路径 | 说明 | 保护 |
| --- | --- | --- | --- |
| GET | `/api/v1/memos` | 时间线，支持 `limit`、`cursor`、`tag` | 公开读 |
| GET | `/api/v1/memos/calendar` | 最近 52 周日历聚合 | 公开读 |
| POST | `/api/v1/memos` | 创建想法 | 口令 |
| PATCH | `/api/v1/memos/{id}` | 编辑想法 | 口令 |
| DELETE | `/api/v1/memos/{id}` | 软删除想法 | 口令 |
| POST | `/api/v1/memos/unlock` | 校验口令，成功返回 204 | 限流 |

请求与响应：

```json
{
  "data": [
    {
      "id": "019a...",
      "content": "刚想到一个更简单的状态拆分方式…… #技术/React#",
      "tags": ["技术/React"],
      "createdAt": "2026-11-09T02:24:00Z",
      "updatedAt": "2026-11-09T02:24:00Z"
    }
  ],
  "meta": { "requestId": "req_123", "nextCursor": "..." }
}
```

```json
{
  "data": {
    "timeZone": "Asia/Shanghai",
    "startDate": "2025-11-17",
    "endDate": "2026-11-15",
    "total": 42,
    "maxCount": 7,
    "days": [
      { "date": "2025-11-17", "count": 0 }
    ]
  },
  "meta": { "requestId": "req_123" }
}
```

- `startDate` 为当前周周一往前 51 周的周一；`endDate` 为当前周的周日；共 52 周 × 7 天 = 364 天。
- `days` 覆盖完整 364 天，按日期升序；未来日期 `count` 为 0。
- `total` 与 `maxCount` 只统计到当前日期。
- 标签筛选不影响日历；日历始终表示全部未删除想法。

### 口令

- 配置键：`Memos:Passphrase`，通过环境变量 `Memos__Passphrase` 或用户机密注入；不写入仓库。
- 最小长度 8；缺失时写接口与 `unlock` 返回 503（`MEMO_PASSPHRASE_NOT_CONFIGURED`），只允许只读。
- 服务端对配置值和请求值分别计算 SHA-256，使用 `CryptographicOperations.FixedTimeEquals` 比较。
- 写请求通过 `X-Memo-Passphrase` 头传递；不得放在 URL、query 或日志中。
- `POST /api/v1/memos/unlock` 只校验口令，不创建会话；前端解锁后把口令保存在 `sessionStorage`（键 `zane-memo-passphrase`）。
- 解锁与写操作按来源 IP 限流：默认 5 次 / 5 分钟；超限返回 429。
- 口令为共享口令，不是用户鉴权；任何获得口令的人都可以修改全部想法。写接口仍限制在本机/内网或受信网络。

## 验收标准

- [ ] 未解锁时可以阅读时间线和日历，但创建、编辑、删除会要求口令。
- [ ] 输入正确口令后可以创建想法，刷新页面后仍存在。
- [ ] `#养花#` 与 `#技术/React#` 被正确解析为标签，并从正文中保留原样。
- [ ] 编辑想法后标签重新解析，时间线顺序与更新时间正确。
- [ ] 删除有二次确认；删除后列表与日历立即排除，刷新后仍不出现。
- [ ] 时间线默认 20 条，游标分页无重复、无遗漏。
- [ ] 日历显示最近 52 周，按 `Asia/Shanghai` 分日，跨 UTC 日期边界正确。
- [ ] 日历 5 档颜色按 0/1/2/3–4/5+ 分档，移动端内部横向滚动。
- [ ] 口令错误返回 401，超限返回 429；前端清除已保存口令并提示重新输入。
- [ ] 加载、空、错误、提交中状态完整；错误不阻塞其他区块。
- [ ] 规则、接口与页面行为有对应测试。

## 开放问题

- 写接口的部署限制采用 Nginx 白名单、VPN 还是仅内网？见部署文档；本 PRD 只要求“非受信网络不可写”。
- 口令忘记后的恢复方式：当前由运维修改 `Memos__Passphrase` 并重启；不提供站内找回。
- 是否为想法保留历史版本？初期不保留，只保留 `updated_at`；版本历史延后。
