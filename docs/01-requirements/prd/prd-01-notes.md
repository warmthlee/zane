# PRD-01 · 思想记录

- 状态：planned
- 阶段：阶段 1（记录 CRUD/检索）；社交分发延后
- 关联：PRD-00、ADR-008

## 背景与目标

沉淀个人思想、技术总结与灵感。核心是“写得快、找得到、不丢失”。社交平台一键分发作为未来能力，当前不进入实现范围。

## 用户故事

- 作为作者，我可以创建、编辑、删除记录。
- 作为作者，我可以用标签组织内容，并按关键词检索。
- 作为作者，我可以区分草稿与已发布内容。
- 作为作者，我可以导出记录，避免数据锁定。
- （未来）作为作者，我可以把记录一键同步到社交平台。

## 数据与接口

- 表：`notes`、`tags`、`note_tags`。
- 接口：`GET/POST /api/v1/notes`、`GET/PATCH/DELETE /api/v1/notes/{id}`。
- 检索初期使用 SQLite FTS5 或 `LIKE` + 索引；优先保证正确性。

## 验收标准

- [ ] 刷新页面后记录不丢失。
- [ ] 关键词与标签可组合筛选，结果正确。
- [ ] 草稿自动保存生效。
- [ ] 导出内容完整可读。
- [ ] 删除操作有二次确认。

## 开放问题

- 记录正文是否保留历史版本？初期建议只保留 `updated_at`，版本历史延后。
- 公开阅读与私有记录的边界如何划分？鉴权延后期间建议写接口仅在本机/内网开放。
