# PRD-02 · 在线工具

- 状态：planned
- 阶段：阶段 2

## 背景与目标

提供无需登录、打开即用的高频工具，降低日常操作成本。首批覆盖编码转换、生成器与参考表。

## 用户故事

- 作为访客，我可以直接使用工具，不需要登录。
- 作为访客，我可以复制或下载工具结果。
- 作为访客，我在输入非法时能得到明确提示。

## 功能要求

| 编号 | 要求 | 优先级 |
| --- | --- | --- |
| TOOL-01 | 工具列表与分类 | P0 |
| TOOL-02 | 二维码生成（文本/URL → 图片，可下载） | P0 |
| TOOL-03 | Base64 文本与文件编解码 | P0 |
| TOOL-04 | ASCII 码表（搜索、复制） | P0 |
| TOOL-05 | 统一三段式布局：输入 → 操作 → 结果 | P1 |
| TOOL-06 | 工具说明与“本地处理”标识 | P1 |
| TOOL-07 | 结果复制/下载 | P1 |

## 实现边界

- 纯计算类工具优先在前端完成，不上传输入。
- 需要服务端的工具必须说明原因，并走 `/api/v1/tools/*`。
- 工具之间不共享可变状态，避免相互影响。

## 验收标准

- [ ] 所有首批工具无需登录可用。
- [ ] 非法输入有可读错误提示。
- [ ] 纯前端工具不发起网络上传。
- [ ] 移动端布局可用。
- [ ] 结果可复制或下载（适用时）。

## 开放问题

- 是否需要工具使用统计？如需要，采用隐私友好方案（见监控文档）。
