# 外部集成清单

所有外部依赖必须通过适配器接入，具备超时、缓存、降级与来源标注。

## 社交分发（延后）

| 项 | 说明 |
| --- | --- |
| 状态 | 延后（ADR-008） |
| 首批平台 | 未来确定，建议先支持一个 |
| 接入方式 | 官方 API / OAuth |
| 数据边界 | 平台凭据仅存服务端密文或引用 |
| 失败处理 | 记录错误、可重试、不重复发布 |

## 热点数据源

| 数据源 | 内容 | 接入方式 | 失败处理 | 状态 |
| --- | --- | --- | --- | --- |
| 百度头条 | 热搜/头条 | 服务端抓取或公开接口 | 缓存 + 时间戳 | 规划 |
| 微博头条 | 热搜 | 服务端抓取或公开接口 | 缓存 + 时间戳 | 规划 |
| 股票信息 | 行情/自选 | 行情 API | 缓存 + 明确标注延迟 | 规划 |

实现约束（.NET 10）：

- 使用 `IHttpClientFactory` 配置超时与重试。
- 使用 `BackgroundService` + `PeriodicTimer` 定时抓取。
- 使用 `HybridCache` 或数据库缓存减少外部调用。
- 适配器实现统一接口，单个源失败不影响其他源。

约束：

- 遵守来源条款与频率限制。
- 不绕过访问控制。
- 展示来源与更新时间。
