# ADR-008 · 社交分发延后

- 日期：2026-11-07
- 状态：已接受（延后）
- 关联：PRD-01

## 背景

一键同步到社交平台依赖平台 API、OAuth、审核与限流，维护成本高，且平台规则变化频繁。

## 决策

社交分发不进入当前阶段。先完成记录、检索、导出与内容生产闭环；未来按以下顺序推进：

1. 选定单一平台并验证发布链路。
2. 抽象同步适配器与状态模型。
3. 增加失败重试与幂等。
4. 再扩展到多平台。

## 影响

- 初版数据模型不包含 `sync_targets` / `sync_records`。
- 记录仍保留“已发布/草稿”状态，导出能力先满足分发需求。
- 相关需求标记为 deferred，未来新增 ADR 再启用。
