# ADR-007 · 鉴权延后

- 日期：2026-11-07
- 状态：已接受（延后）
- 关联：PRD-00、PRD-08

## 背景

站点以个人使用为主，早期先把记录、工具与内容能力跑通。鉴权会引入登录、会话、密码与安全维护成本。

## 决策

当前阶段不实现用户鉴权。写接口在鉴权落地前只允许本机或内网访问，公网仅暴露只读接口。

- 不在初版数据模型中创建 `users` / `sessions`。
- 管理功能不对外公开。
- 未来落地时新增 ADR，采用口令 + 服务端 Session 或 OAuth。

## 影响

- 部署必须通过网络层限制写接口（反向代理白名单、VPN 或仅监听内网）。
- 一旦需要公网写入，鉴权必须先于功能上线。
- 相关需求在 PRD 中标记为延后，不进入当前验收。
