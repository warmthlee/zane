# ADR-002 · SQLite 作为唯一数据库

- 日期：2026-11-07
- 状态：已接受
- 关联：ADR-005

## 背景

单用户、低并发、强调低维护成本、可备份与可迁移。

## 决策

使用 SQLite 单文件数据库，由 .NET 服务端独占访问；通过 EF Core 迁移管理结构。

## 备选

- PostgreSQL：能力更强，但需要额外服务与运维。
- 托管数据库：增加成本与外部依赖。

## 影响

- 写入并发有限，需短事务、WAL、`busy_timeout`。
- 只允许单实例写入；水平扩展需先更换数据库。
- 备份与恢复流程必须纳入发布与运维。
- EF Core SQLite 提供方对部分特性（如某些迁移操作、并发令牌）支持有限，需按提供方能力设计。
