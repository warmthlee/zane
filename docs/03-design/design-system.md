# 设计系统

## 视觉定位

“温暖、理性、可持续记录”的个人工作台。整体像一本长期使用的技术手册，而不是营销落地页：

- 内容与可读性优先。
- 低饱和暖色，避免冷硬或高刺激。
- 深浅双主题，结构一致，只切换颜色。
- 工具页偏功能与效率，内容页偏阅读与呼吸感。

## 设计 Token

颜色、间距、圆角、字体统一定义在 Tailwind 配置与 CSS 变量中，禁止在组件内散落硬编码。

## 间距与圆角

- 基础间距单位：4px；常用 8 / 12 / 16 / 24 / 32。
- 卡片圆角 10–12px；按钮 8px；输入框 8px。
- 页面最大内容宽度 1100–1200px，长文正文 68–76 字符宽。

## 组件来源

- 唯一组件来源：**shadcn/ui**。
- 无特殊情况必须优先使用 shadcn/ui，不另起组件库、不重复实现按钮/输入框/对话框等基础组件。
- 通过 `npx shadcn@latest add <component>` 加入 `src/components/ui/`，组件源码入库并随项目维护。
- 设计 token 映射为 shadcn 的 CSS 变量（如 `--background`、`--foreground`、`--primary`、`--border`），组件通过语义变量取色。
- 主题切换使用 `dark` class；不得在组件内写死颜色。
- 需要变体时优先使用 `cva` 风格扩展，不改动组件的可访问性语义。

## 组件规范

| 组件 | 规范 |
| --- | --- |
| 按钮 | 主/次/危险三级；hover 与 focus 柔和过渡 |
| 卡片 | 轻边框 + 轻阴影；不使用重投影 |
| 输入框 | 明确的 focus 环；错误态显示文案 |
| 标签 | 小尺寸、低饱和；可点击筛选 |
| 代码块 | 等宽字体、浅背景、复制按钮 |
| 空状态 | 说明原因与下一步动作 |
| 加载态 | 骨架屏优先于全屏 spinner |
| 提示 | 行内提示优先，toast 仅用于全局结果 |

## 交互原则

- hover/focus 过渡 150–200ms，避免夸张动画。
- 所有可操作元素有可见焦点。
- 危险操作需二次确认。
- 外部数据展示 `更新时间`，过期时给出提示。
- 深浅主题只切换颜色，不改变布局。

## 可访问性

- 正文与背景对比度 ≥ 4.5:1。
- 图标按钮必须有 `aria-label`。
- 表单错误与输入关联（`aria-describedby`）。
- 支持键盘完成主要流程。
- 尊重 `prefers-reduced-motion`。

## 页面类型差异

| 页面类型 | 设计重点 |
| --- | --- |
| 记录/长文 | 阅读宽度、行高、目录 |
| 工具页 | 输入—操作—结果分区，紧凑高效 |
| 聚合页 | 信息密度、来源与时间标注 |
| Cheat Sheet | 分组清晰、代码块与复制 |
| MVP | 独立入口，允许个性化但不破坏全局 token |
