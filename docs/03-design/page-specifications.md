# 页面规格

## 信息架构

```text
首页 /
├── 想法日历（页内区块）
├── 想法流（页内区块，后端 Memos）
└── 最近文章（页内区块，5 条）

文章 /notes
├── 详情 /notes/:id
└── 编辑（登录）

工具 /tools
└── 工具页 /tools/:slug

游乐场 /playground
└── MVP 页 /playground/:slug

最佳实践 /patterns
热点 /feeds
Cheat Sheet /cheatsheets
管理 /admin（登录）
```

## 首页 `/`

- 定位：轻量想法首页。打开即可看到最近一年的记录节奏，随手写下想法，并进入最近文章。
- 区块顺序：主导航 → 想法日历 → 想法（标题、输入框、时间线）→ 最近文章。
- 标题层级：页面 `h1` 使用 `sr-only`「zane playground · 想法」；日历、想法、最近文章分别使用 `h2`。
- 想法日历：导航下方第一块内容，最近 52 周，品牌橙 5 档；移动端容器内部横向滚动。
- 想法输入框：单列窄版，纯文本，`#标签#` 归类；未解锁时提交会要求口令。
- 想法时间线：按自然日分组，支持行内编辑、删除确认和标签筛选。
- 最近文章：5 条紧凑行，显示日期、分类、标题、阅读时长；完整列表进入 `/notes`。
- 移除旧首页的 Hero、后端状态条、内容板块、引用块、内容方向、写作方向与统计条。
- 状态：想法、日历、文章分别独立处理加载/空/错误；单个区块失败不阻塞其他区块。

## 想法流（首页区块）

- 输入：1–500 字；占位提示 `记录一个想法… 用 #标签# 归类`；字数计数；`Ctrl/Cmd + Enter` 提交。
- 标签：`#养花#`、`#技术/React#`；胶囊显示保留两端 `#`，点击按标签值筛选，当前标签高亮。
- 时间线：按自然日分组，每条显示时间、正文、标签、编辑/删除。
- 口令：未解锁时显示「解锁编辑」；点击写操作弹出对话框；解锁后保存在 `sessionStorage`，`401` 时清除。
- 删除：确认对话框；删除后列表与日历立即更新。
- 空状态：「还没有想法。写下第一条吧。」
- 错误：可读消息 + 重试；提交失败保留输入内容。

## 想法日历（首页区块）

- 7 行 × 52 列，周一开始；每格约 10px，整块高度约 82px。
- 摘要：`过去一年 N 条想法 · 最多一天 M 条`；图例 `少 [5 格] 多`。
- 5 档颜色：0 / 1 / 2 / 3–4 / ≥5 条；颜色不是唯一信息载体，格子带 `title`。
- 月份标签按本地日期生成；未来日期显示空格子。
- 移动端内部横向滚动，默认滚到最右侧当前周。
- 与输入框之间用细线分隔，不使用卡片背景，避免抢占输入框的视觉重量。

## 文章列表 `/notes`

- 区块：搜索框、标签筛选、状态筛选（草稿/已发布）、列表。
- 每条：标题、摘要、标签、更新时间、同步状态。
- 状态：空结果、加载中、请求失败。
- 交互：点击进入详情；支持键盘上下选择。

## 文章详情 `/notes/:id`

- 区块：标题、元信息、正文、目录、同步操作。
- 正文：完整 Markdown 渲染（`react-markdown` + `remark-gfm`），支持标题、列表、表格、引用、链接与代码块；代码块可复制。
- 标题锚点与目录：从 Markdown 标题生成稳定锚点；重复标题追加序号；目录跳转保留 `scroll-mt`。
- 安全：不启用原始 HTML 渲染；链接由渲染器默认转义。
- 同步：选择目标、触发同步、查看状态与失败原因、重试。
- 权限：公开阅读；编辑与同步需登录。

## 记录编辑

- 字段：标题、正文、标签、状态。
- 自动保存：停止输入 1–2 秒后保存草稿。
- 离开提醒：有未保存修改时提示。
- 校验：标题必填，正文非空，标签数量上限。

## 工具列表 `/tools`

- 按分类展示：编码转换、生成器、参考表。
- 每个工具：名称、简介、离线/在线标识。
- 搜索：按名称与关键词过滤。

## 工具页 `/tools/:slug`

- 统一三段式：输入区 → 操作区 → 结果区。
- 必备状态：空、处理中、成功、错误。
- 纯前端工具明确标注“本地处理，不上传”。
- 结果支持复制/下载（如适用）。

首批：

| 工具 | 输入 | 输出 |
| --- | --- | --- |
| 二维码生成 | 文本/URL、尺寸 | 二维码图片，可下载 |
| Base64 | 文本或文件 | 编码/解码结果 |
| ASCII 码表 | 搜索关键字 | 码点、字符、说明 |

## 游乐场 `/playground`

- 展示 MVP 卡片：名称、简介、状态（实验中/已上线/已归档）。
- 每个 MVP 独立路由与独立错误边界。
- 归档 MVP 保留说明页，不保留入口高亮。

## 最佳实践 `/patterns`

- 列表：主题、难度、更新时间。
- 详情：问题、方案、代码、取舍、适用边界。
- 支持与记录共享标签与检索。

## 热点 `/feeds`

- 按数据源分组：百度、微博、股票。
- 每条：标题、来源、时间、外链。
- 显示缓存时间；数据源失败时展示上次结果并标注。
- 股票支持自选列表（P2）。

## Cheat Sheet `/cheatsheets`

- 分类导航 + 搜索。
- 内容以分组清单与代码块为主。
- 代码块一键复制。

## 管理 `/admin`

- 登录后可见：记录管理、同步目标、数据源配置、MVP 注册、备份状态。
- 危险操作（删除、下线、迁移）需二次确认。
- 所有管理操作记录操作日志。

## 通用状态

每个页面必须实现：

- 加载中：骨架屏。
- 空状态：原因 + 下一步。
- 错误：可读消息 + 重试。
- 无权限：说明与登录入口。
