# 页面规格

## 信息架构

```text
首页/工作台
├── 记录 /notes
│   ├── 详情 /notes/:id
│   └── 编辑（登录）
├── 工具 /tools
│   └── 工具页 /tools/:slug
├── 游乐场 /playground
│   └── MVP 页 /playground/:slug
├── 最佳实践 /patterns
├── 热点 /feeds
├── Cheat Sheet /cheatsheets
└── 管理 /admin（登录）
```

## 首页 / 工作台

- 定位：快速进入记录、工具与今日信息。
- 区块：最近记录、常用工具、热点摘要、MVP 入口。
- 状态：未登录时隐藏编辑入口；外部数据失败时展示缓存时间。
- 动作：新建记录、打开工具、进入聚合页。

## 记录列表 `/notes`

- 区块：搜索框、标签筛选、状态筛选（草稿/已发布）、列表。
- 每条：标题、摘要、标签、更新时间、同步状态。
- 状态：空结果、加载中、请求失败。
- 交互：点击进入详情；支持键盘上下选择。

## 记录详情 `/notes/:id`

- 区块：标题、元信息、正文、目录、同步操作。
- 正文：Markdown 渲染，代码块可复制。
- 同步：选择目标、触发同步、查看状态与失败原因、重试。
- 权限：公开阅读；编辑与同步需登录。

## 记录编辑

- 字段：标题、正文、标签、状态。
- 自动保存：停止输入 1–2 秒后保存草稿。
- 离开提醒：有未保存修改时提示。
- 校验：标题必填，正文非空，标签数量上限。

## 工具列表 `/tools`

- 按分类展示：编码转换、生成器、参考表。
- 每个工具：名称、简介、离线/在线标识。
- 搜索：按名称与关键词过滤。

## 工具页 `/tools/:slug`

- 统一三段式：输入区 → 操作区 → 结果区。
- 必备状态：空、处理中、成功、错误。
- 纯前端工具明确标注“本地处理，不上传”。
- 结果支持复制/下载（如适用）。

首批：

| 工具 | 输入 | 输出 |
| --- | --- | --- |
| 二维码生成 | 文本/URL、尺寸 | 二维码图片，可下载 |
| Base64 | 文本或文件 | 编码/解码结果 |
| ASCII 码表 | 搜索关键字 | 码点、字符、说明 |

## 游乐场 `/playground`

- 展示 MVP 卡片：名称、简介、状态（实验中/已上线/已归档）。
- 每个 MVP 独立路由与独立错误边界。
- 归档 MVP 保留说明页，不保留入口高亮。

## 最佳实践 `/patterns`

- 列表：主题、难度、更新时间。
- 详情：问题、方案、代码、取舍、适用边界。
- 支持与记录共享标签与检索。

## 热点 `/feeds`

- 按数据源分组：百度、微博、股票。
- 每条：标题、来源、时间、外链。
- 显示缓存时间；数据源失败时展示上次结果并标注。
- 股票支持自选列表（P2）。

## Cheat Sheet `/cheatsheets`

- 分类导航 + 搜索。
- 内容以分组清单与代码块为主。
- 代码块一键复制。

## 管理 `/admin`

- 登录后可见：记录管理、同步目标、数据源配置、MVP 注册、备份状态。
- 危险操作（删除、下线、迁移）需二次确认。
- 所有管理操作记录操作日志。

## 通用状态

每个页面必须实现：

- 加载中：骨架屏。
- 空状态：原因 + 下一步。
- 错误：可读消息 + 重试。
- 无权限：说明与登录入口。
