# /plan-task

Use this command when starting a new implementation task.

## Required inputs
- Goal: what should be accomplished
- Scope: what is in scope and what is explicitly out of scope
- Constraints: technical, product, or AI workflow constraints
- Acceptance criteria: observable completion conditions

## Procedure
1. Restate the task in plain language.
2. Identify the project boundaries and the "do not do" list.
3. Name the files likely to change.
4. List validation commands that should run before finish.
5. Record risks or unknowns that require human sign-off.

## Output
Provide a concise plan that includes:
- task objective
- file impact areas
- verification steps
- open risks
- explicit done/not-done boundary
